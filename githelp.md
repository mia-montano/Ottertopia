1. Please have a seperate branch for every feature you work on and name it 'project/branch-name' or 'project/your-name/branch-name'

2. All branches must be merged via a pull request so we can track the history of the project
    Steps for this:
    (in the terminal)
        git add .
        git commit -m "commit notes here"
        git push origin project/working-branch
        go to repository in a browser and open a pull request, then merge it

3. If you add an image, please name it what it is and put it in the images folder so we can avoid merge conflicts with images with the same name
